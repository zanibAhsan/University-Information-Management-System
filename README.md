# University-Information-Management-System
C++ object-oriented university management system for undergraduate and graduate students, full-time and part-time professors, courses, registrations, and supervision. Demonstrates inheritance, polymorphism, abstract classes, dynamic memory, pointer arrays, enrollment, course dropping, and centralized data management.


Features
-Student and professor management
-Course registration and dropping
-Undergraduate and graduate student support
-Full-time and part-time professor support
-Graduate student supervision
-Enrollment and course status checks
